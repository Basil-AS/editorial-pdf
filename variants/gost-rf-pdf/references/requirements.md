# Карта применимости

Комплект содержит 21 стандарт, 405 физических страниц исходных PDF. Полные источники, тексты с постраничной разметкой и контрольные суммы приведены в [каталоге](catalog.md). [Проверка каждого стандарта](review-guides.md) охватывает все обозначения комплекта.

| Задача | Применить из комплекта | Проверить дополнительно |
|---|---|---|
| Отчёт о НИР | 7.32-2017, 7.9-95, 15.101-2021 по назначению | Вид отчёта, договорное ТЗ, состав результатов |
| Текстовый документ ЕСКД | Р 2.105-2019 | Форматы, основные надписи и формы по ссылочным ГОСТам |
| Программный документ | 19.101-77, 19.103-77, 19.104-78, 19.105-78, 19.106-78 | Вид и состав документа, исключения, счёт листов ЛУ |
| ТЗ на программу | Комплект ЕСПД и 19.201-78 | Подразделы требований, приёмка, утверждение |
| ПМИ | Комплект ЕСПД и 19.301-79 | Связь проверок с ТЗ, тестовые данные и результаты |
| Межгосударственный стандарт | 1.5-2001 | Формы, структура, обозначение |
| Национальный стандарт РФ | Р 1.5-2012 и адресованные положения 1.5-2001 | Национальные особенности, изменения, формы |
| Библиографическое описание | 7.1-2003 | Тип объекта, уровень описания, редакция |
| Заголовок записи | 7.80-2000 | Вид заголовка, авторство, отличие правил ссылки |
| Электронный ресурс в записи | 7.82-2001 | Доступ, версия, примечания |
| Библиографическая ссылка | Р 7.0.5-2008 | Место, полнота, повторы, комплексные, архивные и электронные ссылки |
| Сокращения в записи | 7.12-93 | Контекст и словарь особых случаев |
| Термины защиты информации | Р 50922-2006 | Определение и область понятия |
| Термины ИБ организации | Р 53114-2008 | События, риски, аудит, менеджмент, меры |
| Формат бумаги | 9327-60 с изменением № 5 | Назначенный A4/A3 и размер каждого листа |

Каждый стандарт включается в запись учёта даже при неприменимости к конкретному заданию. Обоснованное исключение сохраняет предмет стандарта. Например, терминологический стандарт ИБ применяется к тексту по ИБ, правила основной надписи ЕСПД — к программным документам.

## Разрешать различия по виду документа

| Элемент | ГОСТ 7.32 | ГОСТ 19.106 |
|---|---|---|
| Тематическое название рисунка | Под рисунком после пояснений | Над иллюстрацией, номер под пояснениями |
| Примечание одно | «Примечание —» | «Примечание.» |
| Приложения | Буквенные обозначения, статус | При нескольких — арабские номера, обозначение вверху справа |
| Листы | Сквозной счёт с титула, номер снизу по центру | Поля формы с номером вверху, ЛУ вне счёта документа |
| Таблицы | Собственные правила 6.6 | Отсылка 2.6.2 к 1.5-2001 |
| Состав | Структура отчёта о НИР | Структура конкретного программного документа |

При противоречии установи специальное требование для выбранного вида. Сохрани обоснование решения и редакцию. Полный комплект применяется по цепочке отсылок, без автоматического переноса всех параметров ГОСТ 7.32 в другие системы.

## Границы автоматизации

Базовый сборщик создаёт профиль ГОСТ 7.32. Остальные виды требуют собственной вёрстки с использованием источников и маршрутов проверки. Проверка norms.py контролирует наличие источников и полноту записи учёта, а не подтверждает соответствие всем пунктам.

Сохранены предоставленные редакции. Перед утверждением о соответствии действующим на дату сдачи стандартам проверь статус и изменения по официальным данным. Для ссылочных стандартов, которых нет в комплекте, сначала получи текст. Не выдумывай формы, регистрацию, подписи, результаты и даты.
