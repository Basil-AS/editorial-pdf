# Проверка каждого стандарта

Загружай полный текст применимых разделов из каталога перед созданием документа. Ниже дан маршрут проверки. Пункты с формами и изображениями дополнительно проверяй по PDF. Числовые требования и исключения переноси из источника, сохраняя «должен», «допускается», «рекомендуется». Ссылки здесь относятся к редакциям приложенного комплекта.

## gost-r-7-0-5-2008

**Назначение.** Библиографические ссылки на опубликованные, неопубликованные и электронные документы, а также особенности архивных ссылок.

- Разд. 4. Выбери полную либо краткую ссылку, место размещения и правила первичной и повторной записи. Проверь достаточность сведений для идентификации. Для цитирования через вторичный документ укажи происхождение по 4.12. Учитывай специальные правила заголовка ссылки из 4.10.
- Разд. 5. Внутритекстовую библиографическую ссылку заключай в круглые скобки. Отличай её от отсылки к затекстовой записи в квадратных скобках.
- Разд. 6. Подстрочную ссылку размещай как примечание на том же листе. Выбери единый порядок нумерации по 6.3 и проверь его после перепагинации.
- Разд. 7. Свяжи текст с затекстовой записью, при цитировании фрагмента укажи страницы по 7.4.2. Для ненумерованных отсылок используй идентифицирующие сведения по 7.5.
- Разд. 8. Сокращай повторные ссылки только с сохранением однозначной идентификации. «Там же» применяй при условиях 8.10–8.11. После перестановки сносок проверяй заново.
- Разд. 9. Комплексные ссылки разделяй точкой с запятой и сохраняй установленный порядок.
- Разд. 10–11. Для сетевого ресурса проверь сведения о версии, обновлении, доступе, URL и реальной дате обращения. Для архивного документа укажи архив, фонд, опись, дело, листы по применимому типу ссылки. Не добавляй вымышленные реквизиты.

**Проверка.** Ручная сверка описаний и цитат с оригиналом, автоматическая проверка целей ссылок. Сборщик .sources поддерживает затекстовый нумерованный список. Остальные системы требуют отдельной настройки.
