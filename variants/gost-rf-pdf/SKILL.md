# PDF по ГОСТам

## Выбрать требования

1. Прочитай [карту применимости](references/requirements.md), [каталог всех 21 источников](references/catalog.md) и соответствующие главы [проверки каждого ГОСТа](references/review-guides.md). Сверь обозначение и редакцию по содержимому PDF. Учитывай специальное требование пользователя, договор, вид документа и применимость нормативных ссылок.
2. Заведи запись учёта командой python scripts/norms.py plan review.json --kind "Вид документа". Для каждого из 21 стандарт прими решение apply или not_applicable и обоснуй его. Учитывай терминологические и процедурные стандарты в пределах их предмета.
3. Для каждого применимого стандарта прочитай необходимые разделы полностью, включая оговорки и отсылки, через scripts/norms.py read ID --pages N-M. Найди нужные страницы командой search. Смотри оригинальный PDF для форм, чертежей, таблиц и спорных символов. Сохраняй номера действительно прочитанных страниц в read_pages.
4. Перенеси требования в рабочий перечень проверок. Маршруты в памятке группируют требования для навигации. При необходимости добавь в рабочую документацию детализацию до отдельных пунктов, исключений и реквизитов. Для каждого элемента документа установи источник и способ проверки. Сверь ссылочные ГОСТы, отсутствующие в комплекте, и загрузи их при необходимости.
5. Выбери систему оформления. Для общего запроса без вида документа можно использовать ГОСТ 7.32 как явно объявленную основу оформления фрагмента. Для полноценной НИР соблюдай её состав. Для программного ТЗ, ПМИ, ЕСКД и проекта стандарта подбери отдельную вёрстку по источникам. Сохраняй различия подписей рисунков, приложений, примечаний и пагинации между системами.

## Создать документ

6. Сохрани факты, единицы, исходные значения и реквизиты. Проверь состав и иерархию, списки, подписи, нумерацию и первое упоминание объектов. Для библиографии выбери вид записи и систему ссылок, затем проверь каждый первоисточник. Для ИБ сверяй термины по ГОСТ Р 50922 и 53114.
7. Используй [сборщик Markdown](references/build.md) только для профиля ГОСТ 7.32. Для других семейств возьми структуру, поля и формы из полного комплекта. Рендери и сравнивай формы с оригиналом. У ЛУ ЕСПД отдельная пагинация, в счёт документа он не входит.
8. Для широкой схемы, таблицы или целого раздела разрешай альбомный A4 по запросу пользователя и условиям выбранного документа. Сохраняй единый счёт листов, содержание и корректное место номера. При переносе таблицы повторяй предусмотренную головку и подпись продолжения. Сложные объединённые ячейки, многостраничные рисунки и A3 верстай отдельно по соответствующим правилам.

## Проверить результат

9. Запусти python scripts/norms.py verify-sources, проверку PDF и визуальный просмотр отрисованных страниц. Сверь содержание, активные ссылки, номера объектов, фактические показатели реферата, формы, переходы форматов, читаемость и отсутствие потерь таблиц.
10. Заполни статусы проверок в review.json. Для passed укажи конкретное свидетельство, для not_applicable — причину. Выполни python scripts/norms.py check review.json --final. Эта команда проверяет полноту записи и статусы. Содержательность свидетельств сверяет исполнитель.
11. Сообщи фактический охват и оставшиеся ограничения. Отличай учёт всего комплекта, применимость отдельных стандартов и реально проверенное соответствие конкретного документа. Текущую действительность редакций проверяй отдельно при необходимости актуального нормативного соответствия.
