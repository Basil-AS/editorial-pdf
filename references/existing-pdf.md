# Existing PDFs

- Record source page count, order, page boxes, rotation, links, outline, form fields and signatures as relevant. Compare the reopened output against those properties. Keep the original file available.
- Keep fillable forms interactive unless the user asks to flatten them. Verify canonical field values, page widget values and appearance streams. For flattened forms, verify that values render and widgets and form fields are gone.
- Identify signature fields and signed revisions before modifying. Use a workflow compatible with the signature requirements and verify the resulting signatures with the target validator.
- Apply actual redaction to the underlying content, then verify the redacted data is absent from text, images, metadata, attachments and any retained revisions. Inspect final pages and test copy/paste and extraction.
- For scans, retain the source image and page order. Use OCR language packs that match the text and check names, identifiers, and numeric values against the rendered pages.
